# 当前实现

开发目录为 `nbd-claude`，公开仓库为 Leo-learner/nbd，域名为 nbd.dkz12345.com。相邻的原 nbd 目录未修改。

## 契约与行为

48 个 REST 操作由 OpenAPI 契约注册和校验，生成的 openapi.json 与 sdk/generated.ts 可供前端使用。12 个 MCP 工具与 2 个提示词直接使用契约的输入输出 Schema；新版与旧版协议均用官方 SDK 实测。

使用 MCP server/client 2.3.1、Node 适配包 2.1.1；它们的版本独立发布，不要求一致。运行环境为 Node 22，Fastify 5，better-sqlite3 与 FTS5 trigram。

所有者取消自动回看排程：meta.features.reviewScheduling=false，scheduleDays=[]，nextReviewOn=null，reviewStepTotal=0。到期列表为空，推迟返回 NOT_SCHEDULED；保留手动回看、反思、统计和归档。前端不得按旧文档显示到期提醒。

## 身份与隐私

单一所有者使用 Argon2id；会话、Agent 密钥和 OAuth 令牌只保存哈希。OAuth 使用 PKCE、精确回调、白名单客户端元数据、资源绑定、刷新轮换及重放撤销。日志和审计不记录请求正文、密码、密钥或授权码。

REST 幂等请求的成功响应会在私有数据库内缓存 24 小时，以便精确重放；响应可能包含所有者原本可见的正文。MCP 写操作缓存 ID 与元数据。登录、密码修改和密钥签发不缓存凭据。删除记录后，旧幂等响应可能仍留存最多 24 小时，备份保留最多 14 天。

生产信任 nginx 单跳代理；nginx 覆盖转发地址，不直接信任来路不明的 Cloudflare 身份头。2026-10-11 经所有者批准把 NBD 单条 A 记录改为灰云，nginx 接收直接连接地址；本项目尚未启用 NBD 的 fail2ban jail，附带过滤器仅供以后配置。

## 运维

生产启动仅检查迁移状态，部署脚本负责迁移。独立系统用户 nbd，数据目录 0700，systemd 限制写入路径和内存。TLS 由 Certbot 续期；备份每日执行并进行哈希、SQLite 完整性与外键检查，恢复仅允许空目标目录。

部署先检查本地、推送 GitHub，再安装同一提交与 SHA256 校验后的归档。后端版本目录按提交号命名，软链切换和回滚使用唯一临时目录与原子 rename；部署成功后保留最近 5 个并保护当前与回滚目标；失败回退代码、环境文件与 nginx 站点；数据库迁移不自动降级。

## 验证与边界

测试覆盖 REST 契约、权限与 CSRF、冻结和修订、去重与幂等、搜索分页、标签经验库、统计、官方 MCP 客户端、OAuth、备份恢复与清理。真实客户端账号授权不在自动测试范围。

前端已实现登录、时间线与筛选、详情、原话编辑和修订、补记与手动复盘、三类洞察、经验库、标签、回收站、Agent 密钥与已连接应用、设置、导出和操作记录。复盘为独立页面；手机使用右侧导航抽屉。字段类型来自生成的 SDK，枚举和限制来自 `/api/meta`。前端是同源静态应用，不持久化日记、草稿或凭据，不加载外部资源。生产不导入演示数据。

前端按独立版本目录发布，使用逐文件 SHA256 和 HTTP 校验。Fastify 静态资源在请求时读取当前软链，使前端切换无需重启后端；相关回归测试同时验证 SPA 回退与 API/资源 404 的边界。详情见 [FRONTEND.md](FRONTEND.md)。

## 2026-10-11 验收修复

四阶段修复不增加数据库迁移，不改变 REST/MCP 契约。阶段 1 已部署 `5affb7c`；后续阶段的本地结果与线上发布分别记录在 DEPLOYMENT.md 附录 F。

- OAuth 确认与密码重试页只放行已校验的回调 origin；密码错误保留请求/CSRF。授权码换码成功后原子替换旧授权，兼容现有单客户端唯一索引。未签发令牌的授权不展示，满一小时后由清理任务撤销。
- 修订按规范化后的候选快照比较，等价值不产生新版本；编辑器只提交相对基线改动的字段。冲突时保留非重叠草稿，展示全部远端变动及重叠，重叠项逐字段选择后才能保存。版本 k 的来源取修订 k−1，第 1 版是捕获时的「记下」。已有空修订保留。
- OAuth 先校验 grant_type；限流保留 429 与 Retry-After，服务错误保持 5xx 并使用 server_error。操作记录可显示匿名的 auth.login/oauth.login 失败，仅基于本系统单一所有者前提；成功登录标为实际用户名。审计不记录凭据或正文，REST 输出不增加 IP 字段。
- 保持 fresh/reflected 的原状态优先级，复盘文案根据 editableUntil 解释显示时间。新经验在保存复盘时才提交创建，取消草稿不留下经验；删除响应丢失后再清理，404 视为已完成，其他错误仍提示。同日趋势只显示一个日期标签，菜单提供 aria-expanded，指标数字按卡片选择器保持 40–58px。
- 所有 JSON 示例通过契约校验，测试覆盖前端补丁/版本来源、CSP/安全头、readyz 503、代理头伪造、CLI 密码重置、SIGTERM/SIGINT 退出及版本清理。ajv 与 ajv-formats 为显式开发依赖。

Cloudflare 本次选择灰云，后台已保存「仅 DNS」，DoH 返回源站 20.48.14.96，源站 HTTPS/readyz 通过。服务器只读脚本只给汇总，旧备份/恢复与写入验收脚本不自动运行。claude.ai 实际 client_id、手机及 ChatGPT 授权仍需真实账号复验，不以假客户端结果替代。
